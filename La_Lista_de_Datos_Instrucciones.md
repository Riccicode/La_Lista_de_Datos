
PROYECTO: La Lista de Datos

OBJETIVO GENERAL
Adquirir en 30 dias las competencias fundamentales para desempenarse como Analista de Datos con proyeccion hacia Data Scientist, dominando:
- SQL (consultas avanzadas y optimizacion)
- Python (analisis y machine learning)
- Power BI (visualizacion y DAX)
- R (comparativa y analisis estadistico)
- Git (control de versiones y documentacion)

ESTRUCTURA DEL PLAN (30 DIAS)
Cada sesion (3h) se divide en:
- Teoria: 30 min
- Practica: 2h
- Consolidacion: 30 min

DATASETS DISPONIBLES
- BBDD Ventas / Ventas2 -> analisis de ventas
- Enviaments / Comandes -> logistica y pedidos
- Salut_i_son -> salud y sueno
- bestsellers -> prediccion de ventas
- world / Country -> analisis geografico
- hospitals -> rendimiento hospitalario

PROXIMOS PASOS
1. Guardar este documento en la carpeta raiz del proyecto.
2. Crear el repositorio La_Lista_de_Datos en GitHub.
3. Subir las carpetas y los archivos .md al repositorio.
4. Actualizar el Diario de Datos cada dia.
5. Publicar avances semanales.

OBJETIVO FINAL
Tener un portafolio completo que demuestre tu evolucion tecnica desde Analista de Datos hasta Data Scientist Junior.
