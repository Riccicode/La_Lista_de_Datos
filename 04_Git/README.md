# Control de Versiones (Git)

Notas rápidas:
- Flujo recomendado: feature branches → pull request → main
- Mensajes de commit: breve + contexto (ej: "Add EDA Salut_i_son notebook")
- Tags: usar v1.0, v1.1 para versiones públicas

Comandos esenciales:
- git init
- git add .
- git commit -m "Mensaje"
- git push origin main
