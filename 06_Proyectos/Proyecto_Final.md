# 🚀 Proyecto Final Integrador — La Lista de Datos

## 📘 Introducción
Este documento describe el **proyecto final integrador** del plan de estudio *La Lista de Datos*.  
Su propósito es demostrar la capacidad de aplicar SQL, Python, Power BI, R y ML en un flujo de trabajo analítico completo.

---

## 🎯 Objetivo
Analizar un dataset real aplicando todo el ciclo de análisis de datos:
1. Extracción y consultas con **SQL**.
2. Limpieza, análisis y visualización con **Python (Pandas + Matplotlib)**.
3. Creación de un **dashboard interactivo en Power BI**.
4. Implementación de un **modelo de Machine Learning básico**.
5. Documentación profesional en **GitHub**.

## ⚙️ Metodología
### 1. SQL — Extracción y consulta de datos
- Cargar dataset en base SQL.
- Crear consultas JOIN, subconsultas y vistas.
- Exportar resultados a CSV para análisis.

### 2. Python — Limpieza y análisis
- Usar Pandas para limpiar y transformar datos.
- Realizar análisis exploratorio (EDA).
- Graficar correlaciones y patrones.

### 3. Power BI — Visualización
- Conectar dataset limpio.
- Crear KPIs, filtros y visualizaciones.
- Publicar dashboard final.

### 4. Machine Learning — Predicción
- Seleccionar variables predictoras.
- Entrenar un modelo (regresión o clasificación).
- Evaluar rendimiento y explicar resultados.
