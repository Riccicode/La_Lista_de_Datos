# 🧠 La Lista de Datos

### Proyecto personal de formación intensiva en Análisis de Datos y Ciencia de Datos

---

## 🎯 Objetivo General

**La Lista de Datos** es un proyecto de autoformación diseñado para adquirir, en **30 a 45 días**, las competencias esenciales de un **Analista de Datos** con proyección hacia **Data Scientist Junior**.

El plan combina práctica intensiva en **SQL**, **Python**, **Power BI**, **R** y **Git**, con datasets reales y ejercicios de nivel intermedio–avanzado.

---

## 📆 Duración y Metodología

- ⏱ **Duración:** 30 días (3 horas diarias)
- 🧩 **Metodología militar:** teoría (30 min) + práctica (2 h) + consolidación (30 min)
- 📗 **Estructura de aprendizaje:**
  - Semana 1: SQL Avanzado  
  - Semana 2: Python Intermedio–Avanzado  
  - Semana 3: Power BI + DAX + Git  
  - Semana 4: R + Machine Learning  
  - Semana 5 (opcional): Proyecto Final Integrador

---

## 📚 Competencias Técnicas

| Área | Habilidades Clave |
|------|--------------------|
| **SQL** | Subconsultas, JOINs, índices, vistas, optimización de consultas |
| **Python** | POO, Pandas, NumPy, Matplotlib, funciones lambda |
| **Power BI** | Modelado de datos, DAX, KPIs, dashboards interactivos |
| **R** | Análisis estadístico, comparación con Python, visualización básica |
| **Machine Learning** | Regresión lineal y clasificación con Scikit-Learn |
| **Git / GitHub** | Control de versiones, documentación, repositorios públicos |
